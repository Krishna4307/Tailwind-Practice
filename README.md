 # Responsive Portfolio UI Practice
 #Objective
  The objective of this project is to strengthen my frontend development skills by practicing responsive web design and 
  implementing webpage layouts using HTML5, Tailwind CSS, and JavaScript.
  
#Project Description
   This is a practice project created to improve my skills in building responsive websites using HTML5 and Tailwind CSS.
  The project recreates a personal portfolio-style user interface to practice webpage layouts, responsive design, styling, and basic JavaScript interactions. 
  It includes sections such as Home, About Me, Skills, Projects, and Contact.
  The main goal of this project is to gain hands-on experience with Tailwind CSS utility classes, Flexbox, CSS Grid, responsive breakpoints, and DOM manipulation.

#Note: This is a learning and practice project, not my actual personal portfolio website.

# Features
  Responsive portfolio-style webpage layout.
  Navigation links to different page sections.
  Hero section with an introduction and profile image.
  About Me section with sample information and statistics.
  Skills section displaying technical skills.
  Projects section with project cards and images.
  Contact form with name, email, and message fields.
  Basic JavaScript form validation.
  Alert messages for form validation feedback.
  Responsive layouts for desktop and mobile screens.

# Technologies Used
  # HTML5
    Used to structure the webpage, including sections, navigation, project cards, images, and the contact form.
  # Tailwind CSS
    Used to style the interface with utility classes for colors, spacing, typography, Flexbox, CSS Grid, hover effects, and responsive layouts.
  # CSS3
    A separate CSS file is linked for additional or custom styling.
  # JavaScript
    Used to handle button click events, validate the contact form fields, display alert messages, and clear the form fields after successful validation.

  # Note: Tailwind CSS is loaded through a CDN, so an internet connection is required for its styles to load.
